# Netflix Movies and TV Shows – Exploratory Data Analysis

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the Netflix Movies and TV Shows dataset using Python.

The main aim is to understand Netflix content, identify patterns and discover useful insights through data analysis and visualization.

## Objectives
- Understand the Netflix dataset.
- Identify missing and duplicate values.
- Clean and prepare the data.
- Compare Movies and TV Shows.
- Analyse content by country and release year.
- Identify the most popular genres.
- Visualize findings using graphs.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- Visual Studio Code

## Dataset
The dataset contains 8,807 records and 12 columns related to Netflix Movies and TV Shows.

## Data Cleaning
- Checked missing values.
- Replaced missing director, cast and country values with "Unknown".
- Removed rows with missing date_added, rating and duration.
- Checked duplicate records.
- No duplicate rows were found.

## Analysis Performed
1. Movies vs TV Shows comparison.
2. Top 10 countries producing Netflix content.
3. Netflix content released over the years.
4. Top 10 most popular genres.

## Key Insights
- Movies are more common than TV Shows.
- International Movies are the most frequently listed genre.
- Dramas and Comedies are also popular genres.
- Netflix content comes from different countries.
- The release-year analysis helps identify content trends over time.

This project helped identify patterns and trends in Netflix content using Exploratory Data Analysis and data visualization techniques.
